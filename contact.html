Frequently Asked Questions

I forgot my password. What should I do?

On the login screen, click "Forgot password?" and follow the 3-step recovery process. You will need to enter the school name you used when registering. If you also forgot your school name entry, contact your school admin to reset your password from the Admin Panel.

My data disappeared after I cleared my browser. Can I recover it?

Data is stored locally in your browser. If you clear your browser data, the broadsheet data will be lost unless you previously used the "Download Backup" feature. Always download a backup at the end of each session. If you have a backup file (.json), you can restore it using the "Upload Backup" button.

Can I use this on my phone?

Yes. Lagos Broadsheet is fully optimised for mobile phones, tablets, laptops, and desktop computers. On mobile, the table scrolls horizontally so you can access all subject columns.

How is the average calculated?

The average is calculated automatically based on the number of subjects with scores entered. For 2nd Term, if a B/F (Brought Forward) is entered, the average uses subjects × 2. For 3rd Term with B/F, it uses subjects × 3. If no B/F is entered, only the current term's filled subjects are used.

Can multiple teachers use the same account?

No — each teacher should have their own account. This keeps data private and ensures each teacher's broadsheet is separate. A school administrator can manage all teacher accounts from the Admin Panel.

Is Lagos Broadsheet an official LASUBEB platform?

Lagos Broadsheet is an independent tool built to match the LASUBEB examination format. It is not an official LASUBEB government platform, but it is designed to produce results in the same format as the official master sheet.
